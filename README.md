## About

Welcome to **Para's Server Toolkit** — a collection of scripts and tools for managing Linux servers, hosting environments, panels, networking, and VPS utilities. The repository is organized into folders so you can find tools more easily.

## Repository Structure

| Folder | Contents |
| --- | --- |
| [`panels/`](panels/) | Pterodactyl, Jexactyl, MythicalDash, Reviactyl, HVM, WHMCS, Paymenter, Convoy, and related panel tools |
| [`virtualization/`](virtualization/) | Proxmox installers, LXC installer, and Docker container utilities |
| [`networking/`](networking/) | Cloudflare, SSH fixes, Tailscale, Playit, and Nginx utilities |
| [`remote-access/`](remote-access/) | RDP and XRDP tools |
| [`system-tools/`](system-tools/) | Fastfetch installer, backups, RAM swap, AutoSudo, and system utilities |
| [`menus/`](menus/) | Server management menus and VPS tools |
| [`customization/`](customization/) | MOTD builders, themes, and SSL generator |
| [`bots/`](bots/) | Pterodactyl and VPS deployment bot scripts |
| [`misc/`](misc/) | Miscellaneous scripts |

The `LICENSE` file in the repository root contains the project's license.

## Getting Started

1. Open the folder for the tool you need.
2. Read the script before running it and check its requirements.
3. Back up important data and configuration files.
4. Run scripts only on systems you own or are authorized to administer.

For a Bash script, you can usually download or clone the repository, inspect the script, and then run it with the appropriate permissions. For example:

```bash
bash <(curl -s https://hub.ryzencloud.in)
```

Make sure you check each script's contents and instructions before execution. Not every script has the same dependencies or usage.

## Important Notes

- Many scripts are intended for Linux servers and may require root or `sudo` privileges.
- Running installers or administration scripts can change system configuration, install packages, restart services, or modify files.
- Review scripts before running them, especially on production servers.
- Test changes on a disposable or backup environment whenever possible.
- Use these tools responsibly and only with proper authorization.
